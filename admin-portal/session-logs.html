BOT

USER What is the difference between Burst, Normal, and Modulation mode on TENS 7000?
BOT

Normal mode delivers continuous pulse rate and width for immediate acute pain relief. Burst mode sends cyclical packets of pulses (2 bursts/second) to stimulate endorphin release for deep aching pain. Modulation mode periodically varies pulse width and frequency by 50% to prevent sensory nerve habituation.
